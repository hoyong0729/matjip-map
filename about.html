앱으로 설치하는 방법

홈 화면에 추가하면 주소창 없이 앱처럼 열려요.

  • 안드로이드: 크롬으로 열고 → 화면 아래 ‘설치’ 버튼, 또는 오른쪽 위 ⋮ → ‘홈 화면에 추가’ (삼성 인터넷은 메뉴 ≡ → ‘현재 페이지 추가’ → ‘홈 화면’)
  • 아이폰: 사파리로 열고 → 공유 버튼 → ‘홈 화면에 추가’
  • 카카오톡에서 열었을 때: 먼저 ⋯ → ‘다른 브라우저로 열기’(아이폰은 ‘Safari로 열기’)로 연 다음 위 방법대로 해 주세요. 네이버·인스타그램 앱 안에서 열었을 때도 같아요.

YouTube API Services

공개된 영상의 제목·설명·썸네일·조회수를 YouTube API Services로 가져와요. 매일 다시 받아 갱신하고, 지워지거나 비공개가 된 영상은 지워요. 영상을 누르면 YouTube에서 열려요. YouTube 계정 정보에는 접근하지 않아요.

방문 통계

GoatCounter로 방문 수만 세요. 쿠키를 쓰지 않습니다. IP 주소는 국가를 알아내는 데만 쓰고 저장하지 않아요. 남는 건 집계뿐이에요: 본 페이지 주소, 브라우저·운영체제 종류, 화면 크기, 국가, 들어온 경로. (GoatCounter 개인정보 안내)

앱 설치·앱으로 연 횟수도 숫자로만 셉니다 (기기를 구별하는 값이나 위치는 보내지 않아요).

그 밖에 개인을 알아볼 수 있는 정보는 모으지도, 넘기지도 않아요.

내 위치

‘내 위치’를 허용하면 위치는 이 기기 안에서만 가까운 순 정렬·거리 표시·지도 이동에 쓰여요. 저장하거나 어디로도 보내지 않아요. 길찾기 버튼도 내 위치를 넘기지 않아요(지도 앱이 현재 위치를 출발지로 써요). 지도를 그리려고 화면에 보이는 지역의 지도 이미지는 카카오에서 받아 와요.

기기에 저장하는 것

이 기기 브라우저 저장소(localStorage)에 값 일곱 개만 둬요: matjip-yt-notice(첫 안내 확인 시각), matjip-installed(홈 화면 설치 여부), matjip-install-dismissed(설치 안내 닫은 시각), matjip-ios-install-dismissed(아이폰 설치 안내 닫은 시각), matjip-inapp-dismissed(‘기본 브라우저에서 열기’ 안내 닫은 시각), matjip-app-open(앱으로 연 날짜 — 하루 한 번만 세려고), matjip-visits(마지막으로 받은 방문 수 — 통계 서버가 잠깐 안 될 때 보여 주려고). 사이트 데이터를 지우면 사라져요.

화면을 보여 주는 동안 브라우저가 아래 서비스에 직접 요청해요. 각 서비스가 자기 정책대로 접속 기록(IP 등)을 처리할 수 있어요.

가게 정보

  • 가게 이름·주소는 유튜브 영상 설명란 등 공개된 정보를 바탕으로 자동 정리하고, 카카오 지도로 위치를 확인했어요. 폐업·이전·영업시간 변경이 있을 수 있어요.
  • 흑백요리사 출연 셰프의 가게는 뉴스 기사·공개 정리 글을 바탕으로 모으고 카카오 지도로 확인했어요. ‘코스·예약제’ 표시는 그 글에 코스·오마카세로 소개된 가게예요.
  • ‘광고 영상’·‘지원 영상’ 표시는 설명란의 유료광고·협찬·제작지원 표기를 보고 붙였어요. 상세 화면에서 원문을 볼 수 있어요.
  • 맛도리는 유튜버·방송사·가게와 관계없이 개인이 운영하는 사이트예요. 영상과 썸네일의 권리는 각 채널과 YouTube에 있어요.
