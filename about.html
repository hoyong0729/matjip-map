YouTube API Services

공개된 영상의 제목·설명·썸네일·조회수를 YouTube API Services로 가져와요. 매일 다시 받아 갱신하고, 지워지거나 비공개가 된 영상은 지워요. 영상을 누르면 YouTube에서 열려요. YouTube 계정 정보에는 접근하지 않아요.

방문 통계

GoatCounter로 방문 수만 세요. 쿠키를 쓰지 않습니다. IP 주소는 국가를 알아내는 데만 쓰고 저장하지 않아요. 남는 건 집계뿐이에요: 본 페이지 주소, 브라우저·운영체제 종류, 화면 크기, 국가, 들어온 경로. (GoatCounter 개인정보 안내)

그 밖에 개인을 알아볼 수 있는 정보는 모으지도, 넘기지도 않아요. 광고를 싣지 않습니다.

내 위치

‘내 위치’를 허용하면 위치는 이 기기 안에서만 가까운 순 정렬·거리 표시·지도 이동에 쓰여요. 저장하거나 어디로도 보내지 않아요. 길찾기 버튼도 내 위치를 넘기지 않아요(지도 앱이 현재 위치를 출발지로 써요). 지도를 그리려고 화면에 보이는 지역의 지도 이미지는 카카오에서 받아 와요.

기기에 저장하는 것

안내를 다시 띄우지 않으려고 이 기기 브라우저 저장소(localStorage)에 값 세 개만 둬요: matjip-yt-notice(첫 안내 확인 시각), matjip-installed(홈 화면 설치 여부), matjip-install-dismissed(설치 안내 닫은 시각). 사이트 데이터를 지우면 사라져요.

함께 쓰는 외부 서비스

화면을 보여 주는 동안 브라우저가 아래 서비스에 직접 요청해요. 각 서비스가 자기 정책대로 접속 기록(IP 등)을 처리할 수 있어요.

  • 카카오 지도 (지도·장소 검색) — 카카오 개인정보처리방침
  • YouTube (썸네일 이미지) — Google 개인정보처리방침
  • GoatCounter (방문 통계), jsDelivr (글꼴), GitHub Pages (사이트 호스팅)

가게 정보

  • 가게 이름·주소는 유튜브 영상 설명란 등 공개된 정보를 바탕으로 자동 정리하고, 카카오 지도로 위치를 확인했어요. 폐업·이전·영업시간 변경이 있을 수 있어요.
  • ‘광고 영상’·‘지원 영상’ 표시는 설명란의 유료광고·협찬·제작지원 표기를 보고 붙였어요. 상세 화면에서 원문을 볼 수 있어요.
  • 맛도리는 유튜버·방송사·가게와 관계없는 개인 사이트예요. 영상과 썸네일의 권리는 각 채널과 YouTube에 있어요.
