맛도리 이용 안내

2026년 10월 14일부터 적용

맛도리는 유튜버가 다녀간 맛집을 지도에서 찾아보는 개인 비영리 사이트입니다. 회원가입·로그인이 없고, 이름·연락처 같은 개인정보를 받지 않습니다.

YouTube API 서비스 사용

맛도리는 YouTube API 서비스를 사용해 공개된 영상의 제목·설명·썸네일·조회수를 가져옵니다. 맛도리를 이용하면 YouTube 서비스 약관에 동의하는 것으로 봅니다.

  • YouTube 서비스 약관
  • Google 개인정보처리방침

영상 정보는 매일 YouTube 에서 다시 받아 갱신하고, 삭제·비공개된 영상은 지웁니다. 영상과 썸네일을 누르면 YouTube 에서 열립니다. 맛도리는 YouTube 계정 정보에 접근하지 않습니다.

수집하는 정보

방문 통계 하나뿐입니다. GoatCounter 로 페이지 방문 수를 셉니다.

  • 쿠키를 쓰지 않습니다. IP 주소는 저장되지 않습니다 (국가를 알아내는 데만 쓰고 버림).
  • 남는 것은 집계 정보입니다: 방문한 페이지 주소, 브라우저·운영체제 종류, 화면 크기, 국가, 들어온 경로(참조 사이트).
  • 자세한 내용: GoatCounter 개인정보 안내

방문 통계 외에 개인을 알아볼 수 있는 정보를 모으거나 다른 곳에 넘기지 않습니다. 광고를 싣지 않습니다.

내 위치

‘내 위치’ 버튼을 누르면 브라우저가 위치 사용을 묻습니다. 허용하면 위치는 이 기기 안에서만 가까운 순 정렬·거리 표시·지도 이동에 쓰이고, 저장하거나 맛도리·방문 통계 서버로 보내지 않습니다. 길찾기 버튼도 내 위치 좌표를 넘기지 않습니다 (카카오맵·네이버지도 앱이 각자 현재 위치를 출발지로 씁니다).

다만 지도를 그리기 위해 화면에 보이는 지역의 지도 이미지는 카카오 지도 서버에서 받아옵니다.

기기에 저장하는 것

안내를 다시 띄우지 않기 위한 값 세 개만 이 기기의 브라우저 저장소(localStorage)에 둡니다: matjip-yt-notice (첫 방문 안내를 확인한 시각), matjip-installed (홈 화면에 설치했는지), matjip-install-dismissed (설치 안내를 닫은 시각). 브라우저 설정에서 사이트 데이터를 지우면 사라집니다.

함께 쓰는 외부 서비스

화면을 보여 주는 동안 브라우저가 아래 서비스에 직접 요청을 보냅니다. 각 서비스는 자체 정책에 따라 접속 기록(IP 등)을 처리할 수 있습니다.

  • 카카오 지도 (지도·장소 검색) — 카카오 개인정보처리방침
  • YouTube (썸네일 이미지) — Google 개인정보처리방침
  • GoatCounter (방문 통계), jsDelivr (글꼴), GitHub Pages (사이트 호스팅)

가게 정보에 대해

  • 가게 이름·주소는 유튜브 영상 설명란 등 공개된 정보를 바탕으로 자동으로 정리했고, 카카오 지도로 위치를 확인했습니다. 실제와 다를 수 있습니다 (폐업·이전·영업시간 변경 등). 방문 전에 확인해 주세요.
  • ‘광고 영상’·‘지원 영상’ 표시는 영상 설명란의 유료광고·협찬·제작지원 표기를 보고 붙인 것이며, 상세 화면에서 설명란 원문을 볼 수 있습니다.
  • 맛도리는 유튜버·방송사·가게와 관계없는 개인 사이트입니다. 영상과 썸네일의 권리는 각 채널과 YouTube 에 있습니다.
